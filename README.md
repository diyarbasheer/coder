# 🔍 AI Code Reviewer & Auto-Fixer Pro

A web application built with **FastAPI**, **Python**, and **Tailwind CSS** that automatically analyzes code, detects syntax errors and common bugs, and provides instant auto-fixes in real time.

---

## ✨ Features

- **Multi-Language Support:** Analyzes and fixes **Python**, **C++**, and **JavaScript** code.
- **Instant Bug Detection & Auto-Fix:** Catches typos, unclosed brackets/quotes, security issues, and bad practices, then generates a clean, fixed version automatically.
- **Visual Diff Comparison:** Compare your original code with the fixed version side-by-side (`-` removed / `+` added).
- **Code Quality Score:** Displays a live percentage score (`0% - 100%`) based on the health of your code.
- **Session History:** Automatically saves your previous code reviews so you can restore them anytime.
- **Interactive Sound Effects:** Plays fun audio feedback depending on whether your code is clean or has bugs (with a mute option).
